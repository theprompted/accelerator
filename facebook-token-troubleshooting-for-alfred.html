That last part — "sufficient administrative permission" — suggests the issue isn't the token's permission scopes, but the role of the user/system user that generated the token on the BB page itself.

Possible Causes

Three theories, ranked by likelihood

1. Page role insufficient (most likely)

The system user or account that generated the token has Editor or Analyst role on the BB page, not Admin. The error specifically says "sufficient administrative permission" — which is Facebook's way of saying the underlying account doesn't have a high enough role.

Fix: In Business Manager → Pages → Brooke and Belle → Page Access, make sure the system user (or your account) has Admin or Full Control role.

2. App not in Live mode

If the Facebook App is still in Development mode, it can only be used by accounts that have a role on the app itself. Since I'm calling the API from my machine, it might be blocked.

Fix: In the Facebook App Dashboard → App Review → switch to Live mode (if it's still in Development).

3. Token is User token, not Page token

If this is a User Access Token rather than a Page Access Token, we'd need to exchange it for a Page token first. However, the /me/accounts endpoint (which would do this exchange) also fails — which suggests this is already a Page token.

Check: When you generated the token, did you select the Page in the dropdown, or was it generated at the User/Business level?
