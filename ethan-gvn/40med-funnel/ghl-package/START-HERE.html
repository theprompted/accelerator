40 Medications Funnel - Start Here

This download has everything for the 40 Medications funnel launch. Two parts, in order: Part 1 puts the pages on GoHighLevel. Part 2 builds the ads and points them at your new pages.

What's in this folder

  • ad-images/ - the 40 ad images, already sorted into flexible-ad-1 through flexible-ad-4. One folder = one ad.
  • ad-copy/ - the 5 ad texts (copy-1 through copy-5) and the headline (link-headline.txt). Open each file, copy, paste. Nothing to edit.
  • pages/ - the 3 funnels: the-ladder, the-fog, the-prescription. Two pages each. Your Meta pixel is already inside every page and carries over when you paste.
  • page-images/ - the 5 images the funnel pages use.

Part 1: Put the pages on GoHighLevel

  1. In GoHighLevel, open Media Library. Upload the 5 images from page-images/. After each upload, copy the image's URL and keep it somewhere handy.
  2. Create three funnels (suggested names: Tics 2 - The Ladder, Tics 2 - The Fog, Tics 2 - The Prescription), two pages each: page-1 and page-2.
  3. On each page: delete the default elements, add one full-width Custom HTML/Code element, and paste in the entire matching HTML file from pages/. Open the file in any text editor, select all, copy, paste.
  4. Before pasting, swap the image links in the HTML. Search for each line on the left, replace with your Media Library URL:
    Find this in the HTMLReplace with
    src="../../images/ethan-daughters-barn.jpg"your Media Library URL
    src="../../images/kids-cbd-1bottle.png"your Media Library URL
    src="../../images/kids-cbd-3bottles.png"your Media Library URL
    src="../../images/kids-cbd-6bottles.png"your Media Library URL
    src="../../images/kids-cbd-bogo.png"your Media Library URL
  5. Each page-1 has a button that links to ../page-2/. Point it at that funnel's real page-2 URL in GoHighLevel.
  6. Test on your phone: pages load, images show, the page-1 button lands on page 2, the buy buttons work.

When you finish you will have three page-1 URLs, one per funnel. Write them down - they are your ad destinations in Part 2.

Part 2: Build the ads

You are going to make 12 ads in one new ad set. You only build 4 of them from scratch. The other 8 are duplicates where you change a single link. About an hour of work.

Step 1 - build the first 4 ads. This is the only real work.

  1. In Ads Manager, create a new ad set. Name it 40 Medications Funnel.
  2. Create a new ad inside it. Name it Ladder - 1.
  3. Images: add every image from ad-images/flexible-ad-1 (there are 10). Adding multiple images makes it a flexible ad, which means Meta rotates all of them and finds the winners for you.
  4. Primary text: under the text box, click Add text option until you have 5 boxes. Paste one copy file into each (copy-1 through copy-5).
  5. Headline: paste the line from link-headline.txt.
  6. Website URL: your GoHighLevel page-1 URL for The Ladder.
  7. Build 3 more ads exactly like it: Ladder - 2 (images from flexible-ad-2), Ladder - 3 (flexible-ad-3), Ladder - 4 (flexible-ad-4). Same 5 texts, same headline, same URL every time.

Step 2 - duplicate those 4 ads. Rename the copies Fog - 1, 2, 3, 4 and change one thing only: the website URL becomes your page-1 URL for The Fog.

Step 3 - duplicate once more. Rename them Prescription - 1, 2, 3, 4 and the website URL becomes your page-1 URL for The Prescription.

Done: 12 ads, every funnel gets all 40 images and all 5 copies tested against it, and the ad name always tells you which funnel it feeds.
