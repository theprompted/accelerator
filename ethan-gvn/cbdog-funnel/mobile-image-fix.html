Mobile Image Fix

CBDog Funnel

The Problem: Images are displaying too large on mobile devices because they don't have responsive constraints. Here are two ways to fix it.

1 Add CSS to Fix All Images Recommended

Add this code at the top of your HTML, inside the <style> tag. This fixes every image on the page at once.

img { max-width: 100%; height: auto; }
How to do it:
  1. Open your Custom HTML element in GHL
  2. Find the <style> tag near the top
  3. Paste this code right after the opening <style> tag
  4. Save and preview on mobile

2 Add Inline Style to Each Image

If you only want to fix specific images, add this style directly to each <img> tag.

<img src="your-image.jpg" style="max-width: 100%; height: auto;">
How to do it:
  1. Open your Custom HTML element in GHL
  2. Find each <img> tag you want to fix
  3. Add style="max-width: 100%; height: auto;" inside the tag
  4. Save and preview on mobile
