Learning Phase

Idan
Mar 29 — 8:31am

Btw about the learning phase. Can you elaborate on it and how important it is?

If I want an adset to make it out of the learning phase does that mean its better to upload new ads to the same ad set instead of a new one? Or is it considered an edit which resets its process?
Andrew

Learning phase is Meta's way of figuring out who to show your ads to. When you launch a new ad set, Meta needs roughly 50 conversions in a week to "learn" who converts for you. During that period, performance is volatile — CPA swings, ROAS looks ugly, etc.

My approach — if an ad set isn't getting meaningful conversions per day (more than 7 or so), I'd add new ads into it. You're not disrupting much because there's not much to disrupt. But if an ad set is performing well and hitting those numbers, I'd leave it alone. Adding new ads counts as a significant edit that can cause it to re-enter the learning phase. Re-entering doesn't necessarily mean starting from scratch, but it can impact stability — and using other or new ad sets for your fresh creative doesn't create a lot of extra work anyway.

So the rule of thumb: underperforming ad sets are fair game to load new creative into. Performing ad sets — protect them, launch new creative elsewhere.

And don't let learning phase paralyze you. If an ad set is performing poorly, the data from learning phase isn't sacred. Kill it and start fresh.
